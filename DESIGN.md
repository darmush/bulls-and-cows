# Design Bulls and Cows

## 1. Структуры данных и алгоритмы

### `countPossibleSecrets(length, base)` — `src/logic/count-possible-secrets.ts`

Считает количество чисел из length неповторяющихся цифр рекурсивно:

```
countPossibleSecrets(0, base) = 1
countPossibleSecrets(length, base) = base × countPossibleSecrets(length − 1, base − 1)
```

- - Для первой цифры числа есть `base` вариантов. Цифры не повторяются, поэтому для второй остаётся на один вариант меньше, для третьей ещё на один меньше и так далее. Например, для 4 цифр в десятичной системе: 10 × 9 × 8 × 7 = 5040
- Точка остановки — длина 0, когда выбирать больше нечего и вариант один
- Результаты кэшируются через `memoize` из `src/utils/memoize.ts`. Рекурсия вызывает мемоизированную версию, поэтому кэшируются и промежуточные шаги

## 2. Сложность

`n` — длина числа (2–6), `b` — основание системы (2–16).

| Функция                | Big O                             | Обоснование                                                                                                                                   |
| ---------------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `countPossibleSecrets` | O(n) первый вызов, O(1) повторный | Без кэша функция делает `n + 1` рекурсивных вызовов, по одному на позицию. Повторный вызов с теми же аргументами берёт готовый ответ из `Map` |

## 3. Принципы чистого кода

| Принцип                                     | Где применён                                                                                                                                                                                                          |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Говорящие имена**                         | Функции называют действие: `createDigitValidator`, `countPossibleSecrets`. Переменные называют содержимое: `validDigits` в `create-digit-validator.ts`                                                                |
| **Одна функция — одна задача**              | Каждая функция ядра в своём файле в `src/logic/`. Мемоизация вынесена из `countPossibleSecrets` в отдельную `memoize` в `src/utils/memoize.ts`                                                                        |
| **Без дублирования**                        | Алфавит цифр `DIGITS` объявлен один раз в `src/constants.ts` и используется в `createDigitValidator` и `generateSecret`. Валидатор из `createDigitValidator` переиспользуется в `isValidGuess` и при фильтрации ввода |
| **Без магических чисел**                    | Основания систем, ограничения длины и размер таблицы рекордов вынесены в именованные константы в `src/constants.ts`                                                                                                   |
| **Без мёртвого и закомментированного кода** | Неиспользуемых функций и закомментированных фрагментов в `src/` нет; это проверяет ESLint (`no-unused-vars`)                                                                                                          |
